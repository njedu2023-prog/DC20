# 连板路径增量实验：2026-09-21

## 结论与上线决定

已经实际完成两类模型的 A/B/C 历史开发训练和评价。**本轮不替换正式模型。**
不是未训练，也不是宣称路径永远没有价值，而是当前两种接入方式没有证明稳定增益。

- A：原特征基准。
- B：基准 + 当前规则路径标签。
- C：基准 + 9项连续路径数值特征。
- 固定测试区间：2025-11-11—2026-08-14，186个交易日；没有使用9月自然账本结果来训练。
- 固定模型参数、不搜索超参数、不按本次测试结果继续调参。
- 研究标签为已有10:00退出/封板延持，成本0.45%。历史归档的旧开盘退出收益完全不读取。

## 结果

### 晋级

| 指标 | A基准 | B规则标签 | C数值路径 |
|---|---:|---:|---:|
| Top1命中率 | 65.59% | 66.13% | 67.74% |
| Top2命中率 | 54.30% | 55.38% | 51.08% |
| Top3命中率 | 40.76% | 46.20% | 46.20% |
| AUC | 0.69056 | 0.69158 | 0.70267 |
| Brier，越低越好 | 0.19834 | 0.19806 | 0.19524 |

Top1、Top2各186条；2个交易日候选不足3只，Top3各184条，不补造第三名。
C的Top1提高2.15个百分点，五日分块自助法95%差异区间为[-1.61,+5.91]个百分点，包含零。
Top2下降3.23个百分点。不能称为稳定全面提升。

晋级A是同族HGB+Platt的匹配重训基准，不是拿线上已训练到更晚日期的模型回测过去。
所有版本固定HGB参数，禁用内部随机早停；训练标签成熟于2025-09-01前；
校准日期2025-09-01至2025-11-06；测试从2025-11-11开始。
因此不能直接拿本实验65.59%与旧180日留出报告65.00%比较宣称版本增益。

### 盈利：每笔代理成交平均扣费收益

| 指标 | A当前Ridge | B规则标签 | C数值路径 |
|---|---:|---:|---:|
| 盈1 | +0.5212% | +0.0404% | +0.2420% |
| 盈2 | +1.0024% | -0.0038% | +0.1022% |
| 盈1成交胜率 | 48.47% | 41.67% | 47.20% |
| 盈2成交胜率 | 45.03% | 44.52% | 39.62% |

盈利基准逐股分数复现最大误差1.39e-17；重新拟合原模型后误差6.94e-17。
训练5173条/720日，测试1548条/186日；三个版本每日候选和收益标签完全相同。
已知未成交仅在每日席位机会收益中为零，不计作零收益成交；报告同时列出成交数及席位收益。
B/C均没有改善两席平均收益；不能为了完成升级把它们强行上线。
成本增加至0.90%时，B/C两席平均代理成交收益均转负。

## 数据审计

- source_pins.json锁定main beff1605的19份历史特征归档Git blob。
- 共45262个去重D/股票键，没有冲突键；其中10754个满足本轮路径完整性条件。
- 只读取D/code、路径列及覆盖信息，不读取归档T行情或旧交易结果。
- 按D+股票一对一合并，不删掉缺路径的候选；缺失由训练期中位数和缺失标记处理。
- 路径要求至少2个观察日、加权覆盖>=75%、9个数值字段齐全；不满足则路径输入置缺失。
- 盈利训练路径可用率93.72%，测试96.90%；晋级训练61.73%，测试96.72%。
- 数据是历史D特征重建，不是当年实时存档；尚未独立重放每一条原始封板记录。
- 历史强度比较本身可能受跨日字段构成变化影响，本次未偷偷修改旧路径算法。

## 证据边界

本次186日区间此前已被研究查看，是开发验证，不是新的未触碰留出集。
三段时间表现和2000次五日分块自助法仅用于揭示稳定性/不确定性，不构成实盘保证。
没有修改模型激活配置、日常调度、排名、前台、历史冻结记录或影子账本。
结果不能证明所有未来路径模型都无效，也不能证明本次版本已经独立提升。

后续若继续研究，应先验证原始路径重建与缺失一致性，再预先登记新的训练方案，
只在训练期内做特征选择；用真正后续时间窗口检验。不能在本次测试集上反复试到盈利为止。
