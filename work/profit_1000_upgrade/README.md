# 10:00 / 封板延持盈利模型升级

本目录是与正式榜单、模型、影子账本隔离的可复现升级研究入口。
不能因为测试通过、采集成功或训练完成就宣布盈利提升或替换正式权重。

## 按顺序执行

1. `probe.py`：现有凭据最多两次官方分钟读取。2026-09-12 实测
   `600000.SH` 的 20260911、20221114 均通过完整 240 分钟校验。
   [探针运行](https://github.com/njedu2023-prog/DC20/actions/runs/34670144882)。
2. `run.py --output ... --source-zip ... --tail-zip ...`：验证两份完整 ZIP、
   manifest 和各文件 SHA；只导入原始日线/涨跌停证据；原失败记录保留。
   严格复用 6753 个历史候选、910 个 D（20221111–20260814）及 D 日特征。
   不复制旧开盘退出收益，不把回溯重建当作自然前向预测。
3. `collect.py`：先尝试 T 日竞价真值，再按新规则重放结果，仅采集实际缺失的
   股票/交易日分钟证据。固定 9000 次 API、90 分钟上限、最多 4 并发及每秒 2 请求。
   失败、无权限、空数据、缺分钟均保留回执，不填补为成交或零收益。
4. `run.py --evaluate-root ...`：用同一个正式退出计算引擎重建标签。
   按实际退出成熟日期净化训练时间边界；完整日期门槛通过才拟合预先固定的 Ridge。
   训练截止 20251111；之后至 20260814 为已经研究过的开发验证段，不是独立测试。
   Top1 和 Top2 每日均选，负评分或负收益不剔除。
5. 保存候选、逐行预测、数据覆盖与比较结果；禁止自动写入正式权重。
   20260914 起数据预留作前向留出，不可倒灌开发调参。

## 利用原晋级模型

原模型、冻结名单及连板路径展示不改动。历史训练仅使用训练截止早于 D 的 OOF
晋级排名作为新盈利模型输入，并与同候选池晋级排名基线比较。
历史缺少晋级概率、命名连板路径及同历史训练截止的正式盈利排名，因此保持缺失，
不能拿现在的模型回填历史预测。已有 D 日走势与阶段特征保留。

## 仍需验收的边界

- 竞价成交价/开盘价、下一分钟开盘退出均是价格代理，不等于账户实际成交。
  开盘涨停无法确认排队成交、容量不足、跌停不能退出、停牌等状态要保留。
- 新研究按用户最终竞价价指令使用无额外 D 日限价的买入政策；当前正式影子账本
  仍可能受冻结限价约束。两者有明确不同政策 ID，未对齐前不能宣称同口径上线。
- 45bp 为既定成本假设；90bp 压力成本需要同一持仓/成交记录再计算。
  不能用负收益过滤改善胜率，也不能把未完成日期剔除后称为完整资金净值。
- 100 万总资金、每笔 10 万、封板延持造成的资金占用，必须通过重叠持仓资金账
  验收后才能报告实际可复制组合累计净值；当前候选报告只比较槽位收益。
- 新模型至少需要新规则数据完整性、时间顺序比较、前向留出验证和独立上线审查。
  这些步骤未通过时保留原权重，负结果也保留。
