## 接下来的有效流程

protocol.json预先约束：新候选登记后，最早D2026-09-22起形成真实前瞻记录。
日期本身不使数据自动合格，仍须模型/特征/预处理先冻结、T竞价前留下可核验预测凭据。
本次没有登记新的前瞻候选，也没有新增定时采集任务，不会凭协议文件自动开始收集。

未来主目标是盈1和盈2各自同日期的扣费收益；两个席位都需改善，
同时报告成交概率代理、未买/持有/缺失、成本压力和分阶段稳定性。
预设至少120个完整配对D日才进行正式评审，这只是研究下限，不保证统计功效。
未完成的延持交易保留到结算，不能只挑已结算赢家；协议变更重新开始前瞻队列。
两席同时持有、跨日重叠时，不能把逐笔收益简单复利当作100万元账户净值。

当前数据不能支持“独立提升已证明”或“模型升级完成”。
现有路径方案应保留为描述/研究特征，下一版应提出新的可验证特征假设，
而不是在已看过的186日上继续搜索直到盈利。原始分钟证据的覆盖局限仍然存在。
