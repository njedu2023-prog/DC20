# DC20 混合盈利模型：离线亏损归因与两个固定候选

结论：现有混合模型的问题不是漏算手续费，历史持有期毛收益本身也为负；主要损失发生在 T 日收盘到 T+1 日开盘。把学习目标改成成本后期望收益、再加入下行损失惩罚，能在已看历史中减少亏损，但本轮没有得到足以替换生产的盈利模型。所有产物均为离线回溯研究，不能作为放行证据。

## 研究边界与复现

- 原始数据：DC20 自有历史 promotion OOF Top10 账本，910 个 D、6753 行；SHA256 `b3addf99a0f30c784b6a2ae190c3bf6f67f9b1b4a64325193b8d962d6ee2dedd`。
- 只读既有 DC20 数据、特征及保存的历史预测；未读取其他项目，没有修改旧研究/生产文件，没有网络操作、订单或工作流触发。
- `PLAN.json` 在新候选计算前固定：仅两套排序、Ridge alpha=1000、156 个既有 D 日特征、下行惩罚系数0.5；不搜索参数，也不依据结果修改阈值。
- 两个时间窗沿用旧 benchmark：开发窗 2025-02-25—2025-11-18；历史比较窗 2025-11-19—2026-08-14。每窗180个D，各178个完整D参与所有模型共同评价。
- 每一窗训练只使用 `scheduled_exit_date < 窗口首D` 的成熟标签；开发窗训练3675行，最大标签退出日2025-02-24；比较窗训练5239行，最大退出日2025-11-18。变换器只在训练集拟合。
- 排名不得加入晋级概率/晋级名次或结果列作特征；所有模型使用相同候选、相同D、相同费用和持有期。晋级名次仅用于基准，不是新模型输入。
- 两个窗口都已被查看，本次只能称“回溯比较”，不能称未经接触的独立确认或新前向样本。没有资格放行。

## 原始合同审计

账本公式为 `T+1开盘/T开盘−1−0.0045`，压力成本改为0.009。不可买代理的槽位收益固定为0，不可买行没有伪造条件收益。全量账本有8行待真值；共同评价剔除开发窗20250606、20251113和比较窗20260703、20260721，所有模型剔除完全相同的D，原账本未删除这些记录。这个完整日期筛选仍是历史标签可用性限制，不能据此证明无缺失偏差。

既有特征的可用性是“历史退出日严格早于当前D”；本次复核所用全量日历，重新计算已保存延迟特征，并用未来结果污染检查验证隔离。计算结果见 `validation.json`。账本每个D/T/T+1必须是相邻SSE开市日。

原 benchmark 同分时先比较fill、再比较conditional profit；生产合同顺序相反。两个评价窗口存在的联合分完全同分行数为0，因此本次历史Top2不受此差异影响。旧 HGB full-priors 基准的均值、复利和回撤均精确复现。

“可买”只是日线非一字涨停代理，不能证明真实竞价成交、队列容量或滑点。T+1开盘卖出也是代理，没有处理一字跌停无法退出。该缺口会影响交易收益真实性；本轮没有补造真实成交或换退出规则。

## 亏损从哪里来

以下是当前混合模型家族 HGB full-priors 的已查看历史比较窗，178个D，每D两个等权槽位：

| 收益部分 | 每日等权平均贡献 |
|---|---:|
| T开盘到T收盘 | −0.0045% |
| T收盘到T+1开盘，按T买入本金计 | −0.6439% |
| 持有期毛收益合计 | −0.6484% |
| 45bp成本拖累 | −0.4348% |
| 成本后净收益 | −1.0832% |
| 90bp压力成本后净收益 | −1.5181% |

两段收益使用恒等式 `T收盘/T开盘−1 + (T+1开盘−T收盘)/T开盘`，不是简单相加两个不同本金的收益率；所有已成交代理记录都能匹配T收盘价。开发窗也表现相似：T日内−0.0455%、随后隔夜−0.9256%、费用−0.4222%，合计−1.3933%。

这说明手续费不是唯一原因；毛收益已经不够覆盖成本。持有期中的后半段是主要拖累，但这个分解不能证明换一个卖出时间就能赚钱，更不能用T日卖出规避A股T+1约束。

历史比较窗中，可买代理率96.63%，可买条件胜率41.57%；平均盈利+6.943%、平均亏损−6.858%，盈亏幅度比仅1.012，最差10%平均−14.355%，跌幅达到3%的占比46.91%。容易买到并不自动带来收益优势。T开盘相对D收盘的中位溢价约1.31%，它只能用于事后描述，不能作为D日模型已知输入。

相同候选全池等权净收益−1.0233%，旧混合Top2−1.0832%；晋级Top2按本研究T开盘进、T+1开盘出也亏−1.2271%。晋级预测能力不等于这个进出规则下的盈利能力。

## 固定候选比较

新候选直接学习带不可买空仓0的成本后槽位收益；另一个模型学习 `max(−槽位净收益,0)` 的下行幅度。第二套排序使用 `预期净收益−0.5×预期下行损失`。这不是校准概率，也不是严格统计收益下界。

| 排序/离线政策 | 开发窗日均净收益 | 历史比较窗日均净收益 | 比较窗模拟入选/总槽位 |
|---|---:|---:|---:|
| 旧混合HGB Top2 | −1.3933% | −1.0832% | 356/356 |
| Ridge预期净收益，固定Top2 | −0.8330% | −0.8919% | 356/356 |
| Ridge收益与下行，固定Top2 | −0.7515% | −0.6757% | 356/356 |
| 预期净收益正分才模拟投入 | +0.0950% | −0.1307% | 61/356 |
| 收益与下行正分才模拟投入 | +0.0958% | +0.0239% | 17/356 |
| 现金基准 | 0 | 0 | 0/356 |

两套固定Top2仍亏损。收益与下行排序相对旧混合日均改善0.4075个百分点，但5日块、2000次配对bootstrap的95%区间为−0.5859至+1.2127个百分点，跨越0，尚不能确认改善。

最后一行正分策略在历史比较窗只投入17个槽位，其余339个槽位为空仓；日均净收益95%区间为−0.2884%至+0.3248%，复利仅+0.9008%，最大回撤−16.1396%。开发窗只有4次模拟投入，其漂亮收益不能当可靠样本。这些结果主要提示要研究“什么情况下值得承担敞口”，不是证明已经找到新盈利模型。

正分策略只是离线模拟政策。每日2→3→4名单、全部混合排序、Top1/Top2审计账本仍应完整生成；不能把模型拒绝模拟交易和漏记每日账本混为一谈。

## 后续研究应该解决的具体问题

1. 先恢复自然Verify闭环，积累可核验的真实前向T/T+1证据；本轮没有接入任何新权重。
2. 对下一阶段预先固定“成本后收益及下行风险”目标和现金比较基准。若要进入独立研究sidecar，必须记录参数/特征哈希和开始日期，不能复用本轮已看历史作独立确认。
3. 补充可核验的竞价容量、入场价格以及T+1跌停无法退出的真值；当前日线代理不足以确认实盘可执行性。
4. 研究隔夜风险时应遵守T+1可卖日期，不能事后挑选最佳卖价/退出时间，也不能通过只展示少量幸运交易来宣布成功。

本阶段没有生产发布候选。新候选均标记研究状态，保留原有出榜和记账功能。
