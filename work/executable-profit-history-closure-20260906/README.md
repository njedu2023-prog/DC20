不产生订单、仓位、正式 Action。目标是如实检验成本后的 Top1 / Top2，不保证盈利。

## 固定研究方法

标签和训练脚本逐字节复用先前冻结的 execution-v2，参数与政策逐项核对。
原候选 6753 行 / 910 个 D，48 个固定 D 日特征，严格 SSE 日期。缺失中间日期不能
跳过；涨停开盘不假定买到，跌停开盘不假定卖出，除权断点无权益证据则保持未知。
只接受整日候选全部成熟的 D，并要求训练标签成熟日严格早于预测折起始 D。

固定 45bp / 90bp 全程成本假设、每折至少 252 个完整训练日和 1000 行、末端
180 个完整日评估。比较直接净收益预测、净收益减 0.5 倍下行预测、同日期同标签的
晋级 Top2 基线；不回放在完整历史训练的线上混合模型以伪造历史对照。

Top1、Top2 分开报告，已知未成交为现金 0；无第二只时现金占位但不补股票。
正收益率以所有槽位为分母，不是成交后胜率。延迟退出的收益归属原 D，不能冒充
可连续投资的资金净值，不能由此声称真实最大回撤、容量或竞价成交已验证。

## 入口与输出

`run_research.py` 默认仅审计；尾部外部身份未绑定时在标签或拟合前拒绝运行。
只有显式 `--train-after-gates`、完整来源准入和成熟门槛全通过，才在仓库外新空
目录中复制固定输入并进行标签/拟合。两个不可变来源目录都必须在创建 workspace
之前通过不重叠检查。结果独占写入本包新 `outputs/research`，不覆盖旧报告。

仅审计模式使用 `outputs/audit`；本次正式执行的组合审计随结果保存在
`outputs/research/composite_source_audit.json`。`outputs/research/run_manifest.json` 才是本次
训练执行状态。源码登记不代表已训练；尚无结果时不能声称 Top1/Top2 已改善。
本研究始终 `NO_RELEASE`，即使历史结果更好，也必须先对齐执行政策，再单独冻结
并进行自然前向验证，不能据本回顾性试验自动替换线上模型。
