# 连板路径 / 路径变化独立说明层 v2

本次只升级已校验 runtime 特征的**展示解释**。不训练、不替换晋级/盈利模型；不更改任何模型输入、D 名单、排名、收益、买卖规则或已冻结数据。

## 实际上线范围

- 沿用页面已有 D 日期、冻结成员、runtime SHA256、receipt 和版本身份核验。
- 四项核心指标必须逐日完整，连续连板天数必须对应 2→3 或 3→4。
- 独立解读开盘缺口、首封时刻、炸板次数、封单/成交额四个端点变化；不再把一个综合分差当作方向一致的证据。
- 四维存在有效相反变化时优先显示“多维分化”；两维及以上同向且无反向显示“多维增强/多维减弱”；否则“变化有限”。
- 基准描述带：开盘 0.5 个百分点、首封 10 时钟分钟、炸板 0.5 次、封单/成交额 2 个百分点。端点差先由每板斜率乘以板间隔恢复。阈值在 75% 和 125% 时分类不一致则显示“边界变化”，不冒充稳定结论。这些是公开的描述规则，不是训练得到的预测阈值。
- 换手和成交额变化只作辅助事实，不把放量自动解释为买盘承接。
- 明确区分首末板分项比较与相邻两板综合分差；三板端点不能证明中间一天同向。
- “路径变化”显示达到描述阈值的四项方向计数，如“增强3 / 减弱1”，不再把旧综合分差作为主结论。旧分数仍可在 tooltip 追溯，冻结字段完全保留。
- 月度影子账本和首页复用同一展示函数。旧字段仍保留供冻结证据和既有模型使用。
- 说明放入原有 tooltip，不新增页面统计或网络请求；模型、排名和收益字段的来源及解析不改。

## 不应声称的能力

这不是逐笔订单簿验证，也不是分钟事件重建。首封时刻之差不是扣除午休的封板耗时；数据缺口、零成交分钟不能被解释为持续封板。当前没有足够证据在生产页面声称“回封速度”“真实承接”“封单持续性”或准确率百分比。

原始四维并非独立因子，方向一致也不等于上涨/盈利概率提高。高开可能增加买入成本。本次只提高说明透明度、比较口径及保守性，不承诺收益改善。
