# 盈利模型升级：独立历史执行标签重建与候选模型评估

目标是比较成本后的 Top1、Top2 收益及下行风险，不是承诺每日盈利。
这一研究不修改线上晋级模型、连板路径、每日名单、盈利排序权重或 Shadow 账本。

## 方法保持预先固定

- 使用原先冻结的 6,753 个候选、910 个 D 日及 48 个 D 日已知特征。
- 用严格 SSE 交易日历、当日原始日线与官方涨跌停价重建执行代理标签。
- T 日涨停开盘不假定成交；T+1 跌停开盘不假定能卖出。未知中间交易日不能跳过。
- 明确缺失的股票行或必要字段保持未知；不填零、不以前日值替代、不为训练补票。
- 成本场景固定为全程 45bp / 压力 90bp。它们是研究假设，不是实测成交成本。
- 仅完整 D 候选组进入评估；训练标签必须在每一折的预测 D 日之前已经成熟。
- 每折至少 252 个完整训练 D 日、1,000 个训练样本；固定末端 180 个完整 D 日评估。
- 比较直接槽位净收益、直接净收益减 0.5 倍下行预测，以及同样本的原晋级 Top2。
- 保留 Top1、Top2 分别统计、已知未成交的空仓槽位、亏损尾部与回撤。

这些设置逐项与先前 `executable-profit-execution-v2-20260906/PLAN.json`
比较，不能在看到新结果之后修改。原标签和训练脚本按 SHA 校验并原字节复制到
仓库之外的新隔离目录执行，旧研究结果不被覆盖。

## 执行顺序

1. 只读获取固定范围官方历史数据，保存原始响应与带 run/SHA 的哈希清单。
2. `audit_artifact.py` 独立核验下载清单、原始分页、CSV 与已提交重叠来源。
3. 只有 `source_ready_for_label_rebuild=true` 才能创建隔离标签重建目录。
4. `run_research.py` 默认只重建标签并判断成熟度。
5. 显式 `--train-after-gates` 且全部成熟度门槛通过时，才调用固定候选训练。

运行入口要求外部固定的 artifact manifest SHA、audit report SHA、GitHub run ID、
run SHA 与 attempt；不能仅相信 artifact 内部自报的身份。完整性不符、来源冲突、
样本不足均不得产生可发布权重。`PLAN.json` 只绑定一次审查通过的来源版本。

## 不等同于实盘或新前向收益

新获取的历史行情仍是回顾性证据，不是历史 D 日新生成的预测。
日开盘和全日成交量仅提供执行代理，不能证明集合竞价真实成交、容量或资金净值。
复权因子不能单独解决现金分红和股本权益；出现参考价格断点仍保持未解决。

本研究不保存可上线的模型权重，也不能自动接管生产排序。即使历史比较有改善，
还需要独立审查、与线上 Shadow 执行规则对齐，并冻结后进行新的自然前向验证。
若结果不支持改善，结论应是“未证明更好”，而不是调整参数直到收益转正。
