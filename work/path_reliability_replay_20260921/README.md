## 原始过程能支持什么

已有日线与涨停汇总能核验开盘、收盘涨停价、首封/最后封板时间、
开板次数、封单金额与成交额。没有在本实验中取得独立逐笔/盘口事件链。
首封至末封的跨度不等于开板总时长，更不等于封板持续时间，程序不伪造这些指标。
四个分项及旧标签分支按原公式独立重写；日期顺序和连续板数另做严格校验。
本实验采用收盘与涨停价绝对差<=0.005的严格队列，旧引擎使用更宽容差；
时间解析也增加合法交易时段校验，因此不是所有历史生产输出逐字节复现。
价格/汇总来自同一仓库源，只完成内部交叉验证，不宣称独立供应商核实。

## 盲审与准确率验收：待完成

verified_results/blind_review.json含固定哈希顺序选出的60条样本，不含旧规则标签、
候选判断及T/T+1结果。reviewer_a、reviewer_b、adjudicated_label均留空。
审阅者应在不看records.json的条件下依据原始过程独立标注；有分歧必须记录理由并仲裁。
每份结果须填写证据说明和independence_attested，评分器不把空白或旧规则当真值。
该字段是审计声明，不能技术性保证审阅者真的独立。

标注标准应先在开发材料上明确：弱转强至少两个不同维度共同改善；强转弱相反；
加速一致要求首封提前及稳定性/开盘强度共同支持；分歧回封要求真实开板与回封证据；
稳定强势要求连续各日都强且无实质退化；冲突归MIXED，无法核验归INSUFFICIENT。
这些是待审阅确认的语义标准，不用旧数值阈值充当独立答案。

score_review.score同时报告覆盖率、选择性准确率、每类精确率与含拒判的召回率、
双人一致率；不能通过删掉困难样本只报一个漂亮准确率。
60条只是试标样本，不足以可靠评估全部六类，后续须分板位、类别扩充并报告区间。
