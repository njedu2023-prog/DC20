# DC20 可实现盈利专用历史先验研究结论

结论：**否决把本批历史先验并入正式盈利排序。** 六个固定增强变体均为 `REJECT_NOT_CONFIRMED`。确认段虽有部分正向点估计，但 Top2 收益与盈利率提升的 95% 区间都跨 0；所有绝对 Top2 净收益仍为负。该结果不得称为 READY、不得改变前端或交易动作。

机器报告沿用 `confirmation` 字段名表示最后 180 个历史 D 日，但该窗口已经被查看，只是回溯探索段；它不是独立未触碰确认集，也不能作为 forward release evidence。下文“确认段”均按这一受限含义理解。

## 锁定数据与无未来合同

- DC20 自有五年硬池账本：12,322 行、1,210 个 D 日，SHA-256 `7cabe48da6375106b22b2c08c17a7b11780861fed319496ee26761d20fa20a46`。
- DC20 自有历史 OOF Top10 账本：6,753 行、910 个 D 日，SHA-256 `b3addf99a0f30c784b6a2ae190c3bf6f67f9b1b4a64325193b8d962d6ee2dedd`。
- SSE 严格交易日历 SHA-256 `150a3e29ebd6e050d55caee1df218ef5dcfc3542053d8a7478d6be50d09fd748`。
- 任一目标 D 行只能查询 `scheduled/target exit date < D` 的成熟结果；同日退出和未来退出都排除。
- 历史先验分别使用 global、stage、board-stage、stock，expanding、前 20/60 个 SSE 开市日，以及 fill、条件盈利、大亏、收益和样本支持等指标；每个来源固定 108 列并做冷启动收缩。
- 不读取 recovery，不读取或依赖 `top10-decision`，也没有修改 DC20 正式文件。

## 固定评估设计

- 两个独立模型：`P(fill proxy)` 与 `P(net profit > 0 | fill proxy)`；联合概率逐值强制为两者乘积。
- 固定 LR 为主模型、HGB 为敏感性模型；没有根据结果调超参。
- 固定 Top2 两个槽位；缺少候选的槽位按现金 0 处理；不允许看到结果后替换候选。
- 开发段：2025-02-25 至 2025-11-18，180 个 D 日，178 个完整共同面板日；训练只用退出日早于 2025-02-25 的标签，最大实际使用退出日 2025-02-24。
- 确认段：2025-11-19 至 2026-08-14，180 个 D 日，178 个完整共同面板日；训练只用退出日早于 2025-11-19 的标签，最大实际使用退出日 2025-11-18。
- 提升区间采用 2,000 次、5 个 D 日块自助法。固定放行条件为：开发段三方向均正，且确认段 Brier 改善为正、Top2 收益提升和盈利率提升的 95% 下界均大于 0。

## 关键结果

确认段 HGB + 五年全硬池先验相对同类基线：

- 联合 Brier 改善 `+0.00308648`。
- Top2 日均净收益提升点估计 `+0.00316070`，95% CI `[-0.00441892, +0.01142097]`。
- Top2 槽位盈利率提升点估计 `+0.02247191`，95% CI `[-0.02247191, +0.07022472]`。
- 两个区间均跨 0，因此不能确认改善。
