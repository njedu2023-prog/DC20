# 盈利研究扩展数据契约 v2

本工程只积累研究证据，不修改正式模型、排名、费用、交易规则或生产调度；没有自动训练和模型替换。

## 三个时间层

1. D特征：从冻结候选所绑定的 runtime CSV、receipt 和原始晋级名单读取。字段定义、单位、覆盖率、缺失及常量状态由研究台动态展示。新增27项与原29维模型参数分开，不回填旧评分输入。
2. T入场观察：新采集标签保存竞价价来源、竞价成交额、容量及入场资格证据。仅允许公开字段白名单；原终态标签不改写。缺旧证据显示未采集，不从9:30行情推定真实竞价成交。
3. 后续结果：继续使用既有核验后的同口径策略标签；未买入、延持、未结算及缺失保留原状态，不补零或替换成收盘收益。

## 来源、时间和不可变版本

每份D扩展记录绑定原文件SHA256、来源生成时间、第一次研究采集时间及代码版本；内容变化新增版本，旧版本不覆盖。源日期、候选成员、哈希、数值范围和未来时间检查失败时显示缺口，不影响正式产出。

次日凌晨生成但竞价之前的D产物保留并标注晚生成。入场之后生成的扩展可以研究查看，但不计入扩展训练准备日。来源时间只是文件声明，并非独立证实历史盘前可用；所有历史补采仍标注未独立核验时点，不冒充前瞻冻结。

## 扩展字段组

- 晋级概率：原冻结晋级名单概率。
- D日封板和量价：开盘缺口、首末封板时刻、炸板次数、封单成交额比、换手率、量比、成交额对数。
- 连板路径：观测天数、覆盖度、最近两日规则分差、缺口/首封/炸板/封单比/换手/成交额变化、一字板比例、原路径标签与解释。
- 市场环境：情绪规则分、上涨比例、炸板比例。
- 单位核对：runtime的d_turnover_rate已除以100，是比例而不是百分数；d_amount_log是ln(1+daily.amount)，daily.amount以千元计。路径amount_log使用元，两者不可直接混用；各path_*_slope为首末有效值之差除以观测索引间隔，不是未除间隔的总变化；path_strength_delta是最近两次规则分之差。这些说明仅更正研究字典，不重算原runtime输入。
- 分钟摘要：研究采集器独立读取 D 日完整 1 分钟行情，计算分钟对数收益总体标准差（ddof=0，非年化、不是收益平方和开根号）、开盘至10:00收益、14:30至15:00收益。末30分钟明确使用15:00收价/14:30收价−1，不用14:30那根分钟条的开价，避免变成31分钟。完整交易分钟校验未通过，三项均保持缺失。规则版本为d_minute_full_session_log_std_windows_v2，不用盘后或T日行情补D日窗口。

## 独立补采与读取修正

`scripts/profit_research_enrichment.py` 只在 research/enrichment 下追加内容寻址 JSON；不改生产engine、原runtime、模型参数、历史排名、原研究快照或结果标签。最后封板时间优先读取D日原始 limit_list_d.csv，按字符串规范解析整数、整数浮点数及时分秒；解决例如92501.0被错误解释为92时的问题，修正版只用于研究视图。源真的没有时才使用有授权的历史接口补采。

`research_extensions.original_values` 保留原四字段，`value_sources` 指出旁路覆盖的来源；`research_enrichment` 包含完整补采规则、字段状态、来源指纹、实际采集时间和独立快照绑定。历史补采标为HISTORICAL_BACKFILL；即使D事件早于T，今天取回也不能冒充当时已获取。入场前采集标为BEFORE_ENTRY_COLLECTION，但仍不自动签发独立时点核验资格。

三层准备度分别为：全27项扩展特征完整日、原同口径标签成熟日、训练准入日；三者分母和条件不同，不能互相替代。训练准入当前为0，因为尚未完成独立时点审查、训练/验证/测试时间切分与样本独立性审查。原60/120/250进度保留原成熟日口径。

## 日常运行与验收

沿用独立研究任务的生产完成触发和原定时兜底；D特征补采与原策略结果采集分别设置请求总量、单请求超时和总时限，不增加实时行情请求。按股、按D去重，已有完整有效版本不重复调用；失败保留明确原因并允许后续重试。发布时对来源和代码做并发版本检查，研究扩展文件仅写入 research 目录。

验收分别检查旧模型分数/结果不变、来源篡改拒绝、未来时间拒绝、重复采集不改首次时间、历史版本保留、页面质量展示与部署。60/120成熟交易日只是人工评估提示，实际训练前仍需检查时点证据、完整标签、时间切分及样本独立性。
