# 10:00 退出与封板延持

用户于 2026-09-12 决定停用 T+1 开盘卖出，新的日常退出规则为：从严格 T+1
开始，10:00 未封板则发出退出信号；已观察到封板后首次炸板也触发退出；
保持封板则延持，后续交易日使用该日涨停价重新判断。退出挂起后不能因再封板撤销。

适用边界：计划退出日为 2026-09-14 及以后的未完成记录。旧已完成记录不重写，
旧开盘策略只供历史审计，不作为新日期的后备退出规则。仅修改退出，不改冻结
晋级名次、每日盈利 Top1/Top2、现有买入政策、费用或已训练模型文件。

分钟代理约定：时间为北京时间、分钟结束时间；10:00 决策使用已经结束的分钟，
随后一根分钟的开盘价仅作为代理执行价。输出决策时刻、执行分钟起止和代理标识，
不声称具有真实委托成交或逐笔排队证据。不能使用当天收盘判断上午是否封板，
也不能因为执行分钟稍后解封，就推定此前的跌停开盘能够卖出。

缺少完整分钟、涨跌停价、日期或来源证据时保留待验证，不回退到日开盘；封板延持
与数据缺失分别标记。未成交、负预测、负收益记录保留。旧、新规则按版本分别
统计；跨日持仓的逐 D 合成收益不能包装成实际资金净值。

运行方式沿用收盘后验证任务：采集当天分钟行情，再按预先固定的 10:00/炸板规则
回放并结算。这里的 10:00 是退出决策时点，不是任务启动时间；本次不新增盘中提醒
或券商委托。真实分钟接口的权限与首个新规则交易日的数据完整性仍需运行确认。
