# 盈利研究线：排序比较与未来评估登记

本文件只约束独立研究线；不修改正式候选、冻结排名、标签、交易规则或现役模型。当前比较方法从已查看的数据上建立，因此**是探索性描述，不是预注册实验或独立测试**。没有训练、自动升级或交易权限。

## 当前同日比较口径

`scripts/profit_research_comparison.py` 的 `build_comparison(days)` 读取已经过来源绑定校验的研究数据，将结果放入 `research_comparison`。这是全历史口径，不随页面日期、类别或明细筛选改变；原有盈利排名统计保持不变。

1. 共同池是 D 日正式冻结的全部 `profit_eligible=true` 候选，至少两只。每只必须有冻结特征、有效且不重复的晋级/盈利名次、同一冻结模型身份、原策略终态标签和可用日期，且 `training_pair_ready=true`。不合格候选不加入任一策略。
2. 比较盈利前 1、盈利前 2、共同池内晋级前 1、共同池内晋级前 2、共同池全体等权。晋级基准**不等于**包含盈利不合格股票的正式晋级策略。这里不更改原模型分数或排名。
3. 先按冻结名次选取，再观察成交。未成交不递补后面的股票；不能先挑双方都成交的样本。任一合格候选缺标签、待 T/T+1、未核验或状态不合法，整日从所有策略排除。重复日期、重复股票、混合模型也不静默合并。
4. 每个 D 日为每种策略预留相同总资金，所选 K 个槽位各占 `1/K`。每槽收益沿用已核验原策略扣费代理收益；白名单内的 `NO_FILL` 视为该槽资金闲置，资金槽位回报为 0。**这不是零成交收益**，未成交的 `filled_trade_net_return=null`，不计成交胜率、成交均值、最差成交单笔。挂起或缺失永不转换为 0。
5. 先计算各策略每日资金槽位回报，再对日期等权；不能把候选较多的日期隐式加权。比较四个同日差值：盈利前 1 − 晋级前 1、盈利前 2 − 晋级前 2、盈利前 1 − 全合格池、盈利前 2 − 全合格池。资金回报与成交收益分别命名、分别报告分母。
6. 此代理未模拟跨日持仓重叠、总资金约束、实际委托和真实滑点；**不能连乘成账户净值或直接年化**。差值反映该历史共同池内的描述性排序差异，不是因果贡献。

## 不确定性和证据边界

- 完整同日样本不足 20 日：显示均值和覆盖，不计算/展示区间。20 日仅是本描述工具的区间显示门槛，不是有效性、训练或上线门槛。
- 至少 20 日：对成对的每日差值整体重采样，固定随机种子 `20261004`，2000 次有放回抽样，输出 2.5% / 97.5% 百分位区间。两策略不独立重采样，不对单只股票重采样。
- 该区间仅为描述性区间。相邻日期、重复股票、重叠持仓可能相关；当前按日重采样没有消除跨日相关。多种策略比较与已经查看样本也会影响解释。即使区间不跨零，也不自动宣称显著、有效或可升级。
- `days[].strategies[].selected` 保留选中对象、原状态、原名次、资金权重和成交/资金回报；`excluded_days` 保存整日排除原因。产出不写回任何原标签或正式快照。
- 后续如需改方法，应先登记新版本与理由。不得根据已看结果不断更换 Top K、费用、基准或时间窗口，再将最优结果说成独立验证。

## 未来 60 / 120 日评估：待人工确认的预注册模板

以下是**登记模板，尚未批准、尚未填写数值门槛**。60 / 120 日进度只提醒人工评估，不意味着必须训练或自动升级。当前已经查看的日期可用于探索或训练，但不能再充当独立 holdout。未来预注册应在查看拟测试区间结果之前冻结并留版本指纹。

| 登记项 | 必须填写并人工确认的内容 |
| --- | --- |
| 研究目标与主比较 | 主假设、唯一主要比较（例如盈利前 2 对共同池晋级前 2）；其他比较标为辅助，是否使用共同池或更广池 |
| 数据版本与可用性 | 冻结数据 hash、字段/公式版本、来源时间与实际采集时间、盘前可得证据；历史补采与自然前瞻分组 |
| 样本和排除规则 | 日期起止、资格、最小候选数、完整日定义、未成交处理、异常/缺失的固定规则、适用范围 |
| 训练/验证/测试 | 严格时间切分、超参数只用训练和验证、标签跨边界时的剔除/间隔规则、未查看测试期起止；测试最小日数需批准 |
| 冻结基准 | 现役模型精确指纹、晋级基准、全池基准、候选池与策略规则一致；不因后续结果更换 |
| 主要效果门槛 | 最小日等权扣费增益（明确百分点）、不确定性区间下界要求、最小覆盖比例/完整日数；具体值待人工确认 |
| 风险与执行门槛 | 最差成交/尾部损失容忍、成交覆盖/容量、跨日资金占用、费用和滑点压力测试；具体上限待人工确认 |
| 统计计划 | 跨日相关处理（例如固定长度区块重采样）、区间方法/种子/次数、多重比较处理；不能事后挑法 |
| 决策与影子运行 | 保留旧模型、候选新模型版本、只影子运行的期限、人工签字/日期、失败和回退条件；没有自动替换 |

60 日时优先审计数据完整性、时点证据和可执行比较协议。120 日或更多数据时仍需检查上述条件；未通过就继续积累或补齐，不以天数替代证据。250 日只是更长积累窗口，同样不触发自动训练或升级。
