# 独立盈利研究线

公开入口：`outputs/decision/profit_research/index.html`。按年、月、日期、记录类别筛选。
从 D20260914 开始，只读取原正式晋级 Top10（不足10只按实际数），保留未获盈利资格候选。

## 权限与隔离

不训练、不换模型、不改变入场/退出/费用、不改写生产冻结历史。研究任务是正式发布完成后的消费者；失败不会作为正式任务依赖。
每日23:20上海时间另有一次补偿读取，不创建聊天每小时监控。
写入白名单仅为 `outputs/decision/profit_research` 下的研究 JSON。使用 GitHub API 非强制提交；main变化时核对来源绑定、代码和研究目录均未变化，才允许以最新main追加，最多3次。来源变动、差异截断或同目录竞争则拒绝覆盖。
模型特征、标准化参数、系数和公式可公开；凭据、原始供应商行情及内部异常正文不进入公开数据。

## 数据口径

- FORMAL_FROZEN_REFERENCE：引用正式发布层已接受的名单，重新核对名单、快照、日期、成员及SHA；适配器本身不签发发布资格。
- RETROSPECTIVE_UNVERIFIED：有历史名单但没有正式盈利冻结证据，不伪造特征和评分，不进入训练资格。
- SOURCE_ERROR：缺失或指纹不符，逐日显示错误，不拿旧日代替。
- 预测快照逐股不可覆盖；每次结果投影生成内容寻址版本。字段只从显式白名单提取。
- 原盈1/盈2结算直接引用其绑定的正式代理账本。其他候选使用原生固定标签内核独立计算，明确标为 COUNTERFACTUAL_NATIVE_POLICY，绝非实际成交。
- 行情采集最多180次调用/540秒，单请求沿用原20秒限制。凭据缺失、行情拒绝、时间未到保留缺口。
- 原始行情仅存在运行时临时目录；公开保留源指纹及请求时间，但不承诺供应商未来返回完全相同字节。训练前若需要独立长期原文复核，应配置非公开、具有相应存储权利的证据库。
- D特征使用独立enrichment采集器：本地验收可显式指定 `--private-cache` 留存原始响应（权限0700/0600），该目录不得进入Git或公开站点。云端未配置合法非公开持久库时不声称原始分钟行情已长期留档，公开仍只保存研究摘要和来源指纹。
- 不用日开盘代理结果或次日涨幅冒充竞价策略收益。已确认未买入席位可保持策略席位值0，但不进入成交胜率；缺失/未结算永不填0。

## 训练门槛

一天的全部盈利合格候选都有当时冻结特征及成熟同口径标签，才计一个成熟训练日；不合格候选保留原因，不参与分母。
全历史60天/120天仅提示人工评估。没有训练入口、自动参数调整或自动部署新模型。
日后手动训练需另行批准，并先登记比较门槛、按时间切分、标签成熟边界、独立测试和旁路观察方案。

## 验收

`python -m unittest discover -s tests -p 'test_profit_research*.py' -v`
独立任务完成后检查 latest.json 的源版本、内容SHA、页面过滤和完整性计数；受控首次运行不等于未来自然调度实证。

### 运行验收与原文留存

研究任务在采集、标签计算及版本构建后追加不可变运行收据，再生成包含验收摘要的页面数据。收据位于 `operations/receipts/`，只包含白名单状态、时间、哈希及运行编号，不含供应商原文或存储凭据。

- 按上交所交易日历确定应检查的 D 日及下一交易日 T；节假日不按普通工作日推算，日历过期或缺失时不签发通过结论。
- 自然新采集须来自既有定时任务或正式发布后的任务，绑定运行编号、代码版本和实际运行窗口，核对冻结候选、27项扩展字段、分钟完整度及源时间/首次采集时间。已有数据的重放不算新的按时采集证据。
- 手动、代码推送和本地演练单列为受控运行。测试夹具不会计入真实自然运行。
- 按时验收与独立时点核验、训练准入是三件事。自然收集成功也不自动增加训练准入，更不触发训练或替换模型。
- 原文私有云留存默认 `NOT_CONFIGURED`。本地缓存成功、采集任务成功及公开哈希均不代表已长期留存。启用前须由用户指定并授权非公开目的地及相应数据存储权利；未经确认不上传，也不创建可能收费的服务。
- 后续归档须独立读取现存私有缓存，按内容哈希幂等上传并回读校验 SHA256 与长度。不得通过重新请求行情冒充同一份原文，不得修改原采集时间，不得使用公开仓库、Pages 或公开附件保存原文。

机制上线后的第一次受控运行只验证机制能工作；是否在下一个真实交易日按时采到新数据，以届时产生的自然运行收据为准。

## 同日排序比较

研究台提供独立、默认折叠的探索性比较；只纳入同D日共同合格候选全部结果齐全的日期，预先按排名选择，不因未买入补位。策略资金席位收益与成交收益分开。测试样本少于20日不生成置信区间，也不宣称排序有效；20日不是有效性或升级门槛。具体规则、排除原因和后续人工预注册要求见 `docs/profit-research-evaluation.md`。既有盈利排名表和实际模型分数不被改写。
